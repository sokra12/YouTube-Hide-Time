README How to Install the Extension Manually (Google Chrome / Edge) If you downloaded the extension files as a folder from this GitHub repository, you can easily install it by following these steps:

Download the Files:

Click the green Code button at the top of the repository page on GitHub, then select Download ZIP.

Extract the downloaded ZIP file to a folder on your computer.

Open the Extensions Page:

Open your Google Chrome or Microsoft Edge browser.

Type the following URL in the address bar and press Enter:

Plaintext chrome://extensions/ Enable Developer Mode:

In the top-right corner of the Extensions page, toggle the switch to enable Developer mode.

Load the Extension:

Click the Load unpacked button that appears in the top-left/top-right area.

Select the folder containing your extension files (make sure to select the root folder that contains the manifest.json file).

Done:

The extension will instantly appear in your browser's extensions list. You can pin it to the toolbar for quick access.
